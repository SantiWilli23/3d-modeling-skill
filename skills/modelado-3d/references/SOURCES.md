## Investigación web (verifica en la fuente oficial antes de depender de cifras concretas)
- UV/bake/retopo: Graspable (retopo y UV), BlenderCG (bake para juegos), Blender Manual (baking y UV).
- Optimización glTF: guías de optimización de GLB, documentación de `gltf-transform` y `meshoptimizer`.
- Generadores de IA 3D: comparativas 2026 de Cinevva, Indie Hackers; documentación de Tripo y Meshy.
- Reparación de mallas: documentación de trimesh y PyMeshLab, guías de non-manifold.
- Blender headless/conversión: Khronos glTF Tutorials, docs de operadores de exportación de Blender.
- Impresión 3D: guías de preparación de archivos (LBL, TU Delft, Hubs, Meshy).
- Rigging: guías de Rigify, Roblox (skinning humanoide), guías de pesos y límites de influencias.
- Cambios de API 5.0: <https://docs.blender.org/api/5.0/change_log.html> y notas de versión de developer.blender.org.
- Valores físicos de materiales: <https://physicallybased.info/>.

Algunas cifras vienen de blogs y agregadores, no de documentación oficial: tómalas como guía y confírmalas para tu versión/motor.
